비율은 항목별 후보에서 적용합니다. 문장 전체 복원을 선택하면 해당 문장의 개별 빈칸을 하나의 긴 답안으로 바꿉니다. 따라서 난도가 높아져도 칸 수는 줄 수 있습니다. 모든 비율이 0%이면 읽기 모드가 됩니다.

난도를 바꾸어도 입력 기록은 유지됩니다. ‘처음부터 다시 연습’은 확인 없이 모든 답안을 지우며, 난도와 빈칸 위치는 유지합니다.

자료 기준 · 채점 방식 · 저장 안내

내용: 사용자 제공 『산업경영공학 시스템 접근』 제7장 경제성 분석 본문 195–241쪽. 교재의 ‘경제성 개념과 용어 → 경제성 평가’ 전개와 하위 분류를 유지한 학습용 요약입니다. 주요 개념·세부 유형·판단 기준을 복습하도록 재구성했으며, 연습문제 풀이집이나 실제 시험 범위 확정 자료는 아닙니다.

키워드는 동의어·약어·번역어와 조사·어미 차이를 허용합니다. 예: 계층분석과정/AHP, 순현가법/NPV, 분산계수/변동계수, 비용효익분석/비용편익분석. 필요한 용어가 모두 맞으면 나열 순서가 달라도 인정합니다. 이름 뒤에 설명을 길게 덧붙이기보다는 용어를 중심으로 입력하세요. 글자가 비슷하다는 이유만으로 다른 개념을 정답 처리하지 않으며, 최대최소와 최소최대, NPV와 IRR처럼 다른 개념은 구분합니다. 동의어·약어는 미리 정한 정답 사전으로 자동 판정합니다. 문장 전체와 분류 제목은 표현이 다르면 모범답안과 비교하여 직접 확인합니다. AI 의미 판정은 사용하지 않습니다.

수익성은 생산성 설명 아래에, 수익성지수는 순현가법 설명 아래에 배치했습니다. 교재의 용어 ‘분산계수’를 표시하고 통용되는 ‘변동계수’도 인정합니다. 공식의 기호와 적용 조건은 관련 항목에 적었습니다. 본문에 상세한 계산법이 없는 AHP 일관성 지수는 별도 필수 공식으로 추가하지 않았습니다.

입력과 채점 기록은 가능할 때 현재 브라우저에 자동 저장됩니다. 7장과 10장의 기록은 따로 관리됩니다. 파일을 옮기거나 다른 브라우저에서 열면 기록이 이어지지 않을 수 있으므로 ‘학습기록 저장’으로 JSON을 내려받아 보관할 수 있습니다. 외부 서버로 데이터를 보내지 않습니다. iPad의 파일 미리보기가 아닌 JavaScript 실행을 지원하는 브라우저·HTML 뷰어에서 사용하세요. 외부 출처·외부 리소스 미사용.
