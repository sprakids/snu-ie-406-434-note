개인정보처리방침이용안내·약관자료 출처·운영자학습기록 관리·도움말

학습을 시작하는 방법

  1. 메인에서 ‘1~4장 통합’, ‘7장’, ‘8~9장 통합’, ‘10장’ 중 하나를 선택합니다.
  2. 키워드 학습에서는 단원과 난도를, OX 퀴즈와 다지선다에서는 학습 범위와 문제 순서를 선택합니다.
  3. 교재 쪽수 링크를 누르면 해당 페이지가 새 탭에 열립니다. 교재 배율은 1~200%로 조절할 수 있습니다.

한글 조합 중으로 감지된 Enter는 이동·채점에서 제외합니다. 한글 조합이 끝난 뒤 별도의 Enter로 이동해 주세요. 키 입력이 다르게 동작하면 기기·브라우저와 재현 방법을 운영자에게 알려 주세요.

다지선다 입력과 채점

선지 카드나 체크칸을 누르면 선택·해제되며 입력칸에도 같은 조합이 표시됩니다. 직접 입력한 조합도 체크칸에 반영됩니다. 교재 쪽수 링크는 선택을 바꾸지 않고 교재를 엽니다. 선택 후 채점하기를 누르며, 채점한 선지는 다시 풀기를 누른 뒤 바꿀 수 있습니다. 키보드로는 Tab으로 체크칸에 이동한 뒤 Space로 선택할 수 있습니다.

각 문제의 다섯 선지 중 옳은 것을 모두 눌러 선택하거나 입력합니다. ㄱㄴㄷ과 123은 같은 조합이며, ㄷ ㄱ처럼 순서를 바꾸거나 띄어 써도 됩니다. 선지 표기는 한글·숫자 중 바꿀 수 있습니다. 같은 선지의 중복 입력이나 1~5 밖의 기호는 입력 오류로 안내하며 풀이로 집계하지 않습니다.

입력칸에서 Enter 또는 채점하기를 누르면 정답 조합, 빠뜨린 선지, 제외할 선지와 다섯 선지의 참·거짓 및 교재 근거를 확인할 수 있습니다. 정답 개수는 1~4개이며 정확히 일치해야 정답입니다. 핵심 개념 및 키워드를 중심으로 같은 학습 항목·단원의 관련 개념을 함께 비교합니다. 선지별 출처가 다를 수 있으므로 각 쪽수를 확인하세요.

문제를 열거나 이전·다음 이동, 문제 번호 이동, 다시 풀기로 다시 표시할 때마다 선지를 새로 섞습니다. 채점 결과를 보거나 선지 표기만 바꾸는 동안에는 현재 배치를 유지합니다. 답안은 선지 내용에 연결해 저장하므로 순서가 바뀌어도 정답·오답 기록은 유지되며, 이전 선택과 초안은 새 번호에 맞춰 표시됩니다. 입력 중에는 답안을 가공하지 않으며 한글 조합 중 Enter는 채점에서 제외합니다.

화면 모드

상단의 다크 모드 스위치로 라이트·다크 모드를 바꿉니다. 처음에는 기기의 설정을 따르며, 직접 선택한 뒤에는 이 브라우저에서 선택을 유지합니다. 키워드·OX·다지선다·교재·안내 페이지에 같은 모드를 적용합니다. 교재 이미지는 원본 색상을 유지합니다. 기기의 동작 줄이기를 켜면 전환 애니메이션을 줄입니다.

내 학습기록 확인·내려받기

현재 주소의 이 브라우저에 저장된 기록만 확인합니다. 1~4장과 8~9장은 각각 한 묶음이며, 키워드·OX·다지선다 기록은 각각 따로 저장됩니다. 다른 기기나 다른 도메인에 남은 기록은 여기에서 조회하지 못합니다.

기록을 확인하고 있습니다.

이 통합 파일은 키워드·OX·다지선다 기록을 함께 보관하고 내용을 확인하는 용도입니다. 현재 통합 파일 불러오기는 지원하지 않습니다. 키워드 노트에서 복원하려면 해당 노트 하단의 ‘학습기록 저장’으로 만든 개별 파일을 ‘학습기록 불러오기’에서 선택해 주세요.

기록 수정·삭제

  • OX·다지선다 다시 풀기: 문제 상단의 ‘이 문제 다시 풀기’는 해당 답안·초안만 지웁니다. 출제 설정의 ‘전체 다시 풀기’는 현재 장 묶음을, ‘선택 단원 다시 풀기’는 선택한 단원의 전체 문항을 다시 시작합니다. 확인 창에서 범위와 기록 수를 확인한 뒤 실행하며, 취소하면 기록을 유지합니다. 실행 후 학습 범위는 전체 문제로 바뀌고 문제 순서·선지 표기 설정은 유지됩니다. 다른 단원·장과 다른 학습 방식의 기록은 유지됩니다.
  • 답안 수정: 키워드 입력칸에서 직접 고칩니다. OX와 다지선다는 답을 제출한 뒤 ‘이 문제 다시 풀기’로 해당 답을 지우고 다시 답할 수 있습니다.
  • 키워드 답안 초기화: 노트의 ‘현재 범위 비우기’ 또는 ‘처음부터 다시 연습’에서 삭제 범위를 확인하고 실행합니다. ‘1~4장 통합’ 전체 초기화는 네 장 답안에, ‘8~9장 통합’ 전체 초기화는 두 장 답안에 함께 적용됩니다. 난도 설정 등은 남을 수 있습니다.
  • 키워드·OX·다지선다·설정까지 삭제: 이 사이트가 열린 다른 탭을 먼저 닫고, 브라우저 설정의 사이트 데이터 관리에서 현재 도메인 snu-ie-406-434-note.vercel.app의 데이터를 삭제합니다. 브라우저와 버전에 따라 메뉴 이름이 다를 수 있습니다. 다른 사이트의 데이터까지 지울 필요는 없습니다.
  • 내려받은 파일: 사이트 데이터 삭제와 별개입니다. 다운로드 폴더·기기 백업에 남은 JSON 파일은 직접 삭제해 주세요.

서버에 학습 기록 사본이 없으므로 운영자는 삭제한 기록을 복구할 수 없습니다. 공용 기기나 비공개 모드에서는 특히 필요한 기록을 먼저 파일로 보관해 주세요.

자주 묻는 질문

기기나 브라우저를 바꾸면 기록이 이어지나요?

자동으로 이어지지 않습니다. 같은 기기라도 브라우저 프로필이나 사이트 주소가 다르면 저장 공간이 다릅니다. 예전 주소 ie-ch10-keyword-notes.vercel.app의 기록도 현재 주소와 별도입니다.

무작위로 섞으면 풀이 기록이 사라지나요?

OX와 다지선다의 순서 변경과 다시 섞기는 답안을 지우지 않습니다. 단원 순서 모드로 돌아가도 기존 풀이 기록은 유지됩니다.

교재가 비어 보이면 어떻게 하나요?

‘다시 시도’를 눌러 보고, 연결 상태를 확인해 주세요. 계속 열리지 않으면 ‘원본 화질 PDF로 열기’를 이용할 수 있습니다. 통합 교재의 다음·이전 쪽은 노트에 포함된 장 범위 사이를 이어서 이동합니다.
