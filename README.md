# 산업공학의 이해 학습 사이트

서울대학교 「산업공학의 이해」(406.434) 복습을 위한 정적 웹사이트입니다.

사이트: <https://snu-ie-406-434-note.vercel.app/>

## 학습 기능

- 1~4장 통합, 7장, 8~9장 통합, 10장 키워드 빈칸 학습
- 교재 출처가 연결된 OX 퀴즈와 다지선다
- 문제·선지 순서 변경, 한 문제·선택 단원·장 전체 다시 풀기
- 교재 페이지 바로 열기와 1~200% 배율 조절
- 한글 입력과 외장 키보드 이동, 라이트·다크 테마

답안·진도·설정은 각 브라우저의 `localStorage`에 저장합니다. 서버 데이터베이스나 계정 간 학습 기록 동기화 기능은 없습니다.

## 로컬 실행

별도 빌드 없이 저장소 루트에서 정적 파일 서버를 실행합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8000/>을 엽니다. 문항 데이터를 `fetch`로 불러오므로 HTML 파일을 직접 여는 대신 서버를 사용합니다.

## 테스트

Node.js에서 다음 명령을 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```powershell
node --test tests/*.test.cjs
```

## 파일 구성

- `index.html`: 메인 화면과 키워드 노트 탐색
- `chapter-*.html`: 키워드 빈칸 노트
- `quiz*`, `multi*`, `study-retry.js`: 퀴즈 데이터·채점·다시 풀기
- `textbook.html`, `assets/`: 교재 PDF·페이지 이미지·로고·글꼴
- `campus*`: 공통 디자인·테마·효과·탐색
- `authoring/`: 문항 생성과 자료 정합성 확인에 사용한 도구·원자료
- `tests/`: 문항·채점·저장·다시 풀기 동작의 회귀 테스트

## 배포와 자료 권리

Vercel에서 저장소 루트를 정적 사이트로 배포할 수 있습니다. `.vercelignore`는 배포에 불필요한 개발 자료를 제외하고, `.gitignore`는 로컬 Vercel 연결 정보와 환경 변수 파일 등을 제외합니다.

교재·로고·글꼴 등 자료의 권리는 각 권리자에게 있습니다. 이 저장소에 포함됐다는 이유로 해당 자료에 별도 재배포 권한이 부여되지는 않습니다. 글꼴 라이선스는 `assets/fonts/`에 포함돼 있습니다.
